# Design direction — Workbench

## World

A calm, high-clarity team dashboard: pale mineral green work surfaces, forest-black navigation, soft modular task panels, and a decisive chartreuse action color.

## Type and layout

Use a sturdy geometric sans for hierarchy and a neutral sans for task copy. Keep the project context and status counts above the board, then give each workflow column clear ownership without nest-after-nest card framing.

## Interaction

Task cards support click, keyboard focus, and drag-and-drop. Project changes carry the selected project's accent through the full header and move the board as one brief, restrained transition.
