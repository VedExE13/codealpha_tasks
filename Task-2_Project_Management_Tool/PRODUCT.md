# Product

Workbench is a collaborative project management tool for small teams. A user should be able to create a project, divide work into tasks, assign people, and leave notes where the task is tracked.

## Audience and job

Small groups coordinating work across a shared board, especially when they need a quick view of what is waiting, moving, and complete.

## Product facts

- Projects and task records are stored in SQLite.
- Signed-in users can create projects; owners can invite an existing account by email.
- Members can create and update task cards, assign a member, change status, and comment.
- New accounts receive a starter project and sample tasks.
- Projects are stored locally by each installation; the database is excluded from Git.

## Preserve

Keep board state, assignments, collaboration, comments, and project switching immediately findable. Do not make the dashboard imply analytics the product does not calculate.
